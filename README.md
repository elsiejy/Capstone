# Elsie's Capstone

Project
1. Hospitality Analytics - Hotel Bookings
\
Problem statement: How can the hotel leverage historical booking data to identify seasonal booking patterns, understand the characteristics and booking behaviours of key customer segments, and investigate factors associated with booking cancellations? Based on these insights, what data-driven strategies can the hotel implement to optimise demand management, improve customer targeting, and reduce booking cancellations?

2. Customer Analytics - Telecom Churn Analysis
\
Problem statement: How can the telco leverage historical customer data to identify key factors associated with customer churn, determine which customer segments are most likely to leave, and develop a predictive model to identify customers at high risk of churning? Based on these insights, what targeted customer retention strategies can the telco implement to reduce its churn rate?

4. Transport & Mobility Analytics - Singapore MRT Analytics
\
Problem statement: How can historical MRT/LRT ridership data be used to identify passenger demand patterns, assess variations in station usage over time and support more effective public transport planning and resource allocation? The findings will be used to recommend strategies to improve public transport resource allocation and service planning.
